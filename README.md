# Shivom Pandey Portfolio

Static portfolio site for Vercel.

## Deploy

Import this repository into Vercel and use the project root as the deployment root. No build command or framework preset is required; Vercel can serve the files as a static site.

## Files

- `index.html` - portfolio content and page structure
- `styles.css`, `mentoring.css` - responsive styling
- `script.js` - year label and appointment email draft
- `vercel.json` - static URL settings
- `shivom-linkedin-thumbnail.png` - LinkedIn thumbnail
- `shivom-linkedin-thumbnail.svg` - editable thumbnail source
